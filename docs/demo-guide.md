# 页织工作空间

打开后先到项目首页：切换项目、看画布卡片、创建空白画布、看最近资产和提醒。活动页、首页换风格、会员日页面、上线检查是列表里的示例画布，组件库也在品牌资产里。从画布点「返回首页」回来。新建画布会记在这台浏览器里，刷新后仍在首页列表中。

生成、检查、作业和身份切换都在本机模拟，没有接入模型、真实构建或账号系统。相关位置会标明「模拟」或「未接入」。

数据在浏览器 `localStorage`（`yezhi.workspace.v1`）。旧的 `yezhi.demo.v1` 会读进来，其中的预制画布标为示例。辅助菜单里的「重置示例画布」只恢复示例，不删除你新建的项目和画布。

## 通用操作

1. 在空白处右键，添加七类节点。节点落在点击对应的画布坐标上。
2. 选中节点后，在节点下方写指令。微调或补充出新版本；派生或另做会新建；没写明会先问。永久冻结的节点仍可提交，但只会派生，不会改原节点。
3. 从圆点拖出的是整节点引用，从方点拖出的是某一项。选中或悬停时，无关连线会变淡。
4. 点卡片上的产物摘要，打开详情。页面在隔离框里预览。
5. 资产按七类卡片浏览，引用绑的是选定版本，不复制内容。

权威产品说明见 [yezhi-product-spec.md](./yezhi-product-spec.md)。
