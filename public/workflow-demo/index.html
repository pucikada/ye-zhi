任务运行流可视化方案

流程：需求澄清 → 需求设计 → 代码开发 → 代码检视 → 界面验收 → 代码提交。
自动准出：满足 hook 校验直接过； hook 重试：校验失败后按上限 x 次自动再跑（不是用户主动重试）； 人工准出：x 次仍失败后人工介入。
用户本步重试：用户对当前步骤主动再跑，通常附带额外提示词； 跨步跳回：失败回到更早步骤。三者互不混用。

正常前进 自动准出 hook 自动重试 人工准出 用户本步重试（含提示词） 跨步跳回 示例窗口：近 7 日 · 128 单 · Asia/Shanghai

卡片流程 + 上方回流弧

卡片展示耗时与准出三元组；青色徽章为用户本步重试（点击卡片查看提示词）。玫红弧为跨步跳回。

铁路 / 轨道图

主干道=前进；站内青色小环=用户本步重试；上方返回轨=跨步跳回。站点盒内含准出三元组，可点开提示词。

链路追踪时间线

同行连续青块=用户本步重试；黄块=hook 自动重试；玫红弧=跨步跳回。点击色块可看提示词气泡。

点击时间线上的青色「用户本步重试」色块，可查看该次提示词。
