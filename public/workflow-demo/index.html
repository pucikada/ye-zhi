任务运行流可视化方案

数据固定：需求澄清 → 需求设计 → 代码开发 → 代码检视 → 界面验收 → 代码提交。 青色表示本步重试（用户在当前步骤自己再跑）， 玫红虚线/弧表示跨步跳回（失败回到更早步骤）。二者互不计入。

正常前进 本步重试 跨步跳回 人工审批 执行耗时 示例窗口：近 7 日 · 128 单 · Asia/Shanghai

卡片流程 + 上方回流弧

横向精致卡片承载指标；卡间短箭头表示前进；玫红弧从上方绕回表示跨步跳回；青色徽章表示本步重试。

铁路 / 轨道图

步骤像站点排在主干道上；站内青色小环 = 本步重试；上方并行返回轨 = 跨步跳回。

链路追踪时间线

更大、更清晰的单次运行甘特图。同行连续块 = 本步重试；玫红弧 = 跨步跳回后重入。

转移矩阵热力图

行 = 起点，列 = 终点。对角线青色 = 本步重试；左下玫红 = 跨步跳回；右上青蓝 = 正常前进。

垂直旅程故事流

从上到下讲述一单完整路径；失败跳回用回湾提示条标明，再画出重新进入的事件块。
